# Carousel Builder Agent

Универсальный агент для создания Instagram-каруселей под любую нишу и язык.

## Что делает агент

Агент превращает тему пользователя в готовую карусель:

- пишет весь текст слайдов;
- выбирает структуру из 6–10 слайдов;
- создаёт обложку с сильным hook;
- принимает решения по палитре и шрифтам;
- собирает визуальную систему;
- добавляет CTA и при необходимости дисклеймер;
- готовит отдельные PNG-слайды в формате 4:5;
- собирает PDF и ZIP с файлами;
- проводит лёгкую проверку читаемости, порядка слайдов и соответствия CTA.

## Как запускать

В первом сообщении передайте тему, CTA, хэндл и название бренда. Остальные параметры можно оставить пустыми.

```text
Тема: как быстро собрать воронку продаж в Telegram с помощью ИИ
CTA: написать «ВОРОНКА» и получить шаблон
Хэндл: @example
Название бренда: AI просто
Аудитория: эксперты и владельцы малого бизнеса
Язык: русский
Тон: экспертный, дружелюбный
```

Агент сначала задаёт короткие вопросы intake одним сообщением. До получения обязательных ответов он не начинает сборку и не рендерит файлы.

## Обязательные данные

Без темы, CTA и хэндла агент не переходит к производству. Название бренда можно заменить хэндлом, если пользователь его не указал. Палитра, фото для обложки, тон и дополнительные факты — необязательные.

## Результат

Итоговый пакет должен содержать:

1. Markdown с текстом и логикой карусели.
2. Отдельные PNG каждого слайда 1080×1350 px.
3. PDF карусели.
4. ZIP-архив с материалами.
5. Краткую заметку о выбранной палитре, шрифтах и допущениях.

## Важные правила

- Формат по умолчанию — 4:5, 1080×1350 px.
- Карусель содержит 6–10 слайдов.
- Один слайд раскрывает одну мысль.
- На каждом слайде максимум один главный акцент.
- Основной текст должен иметь высокий контраст.
- Не выдумывай название бренда, хэндл, факты, кейсы, цифры или обещания.
- Для финансовых, медицинских и юридических тем добавляй корректный дисклеймер.
- Используй только общие механики, не копируй чужие тексты и дизайн.
